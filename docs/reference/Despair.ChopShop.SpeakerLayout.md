## Despair.ChopShop.SpeakerLayout.Center

Сигнатура не восстановлена: записи нет в Lua-заглушках.

Enables or Disables the center speaker.

Поля параметров call-tip (интерпретация структуры, не восстановленные типы):

| № | Имя (`@K[209]`) | Описание (`@K[211]`) |
| --- | --- | --- |
| 1.0 | On | Boolean to turn on or off speaker |

<details><summary>Исходная структура call-tip</summary>

```json
{
  "@K[202]": {
    "1.0": {
      "@K[209]": "On",
      "@K[211]": "Boolean to turn on or off speaker"
    }
  },
  "@K[203]": "Enables or Disables the center speaker."
}
```

</details>
