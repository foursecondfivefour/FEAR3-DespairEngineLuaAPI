## Despair.Smash.Mouse.Move

Сигнатура не восстановлена: записи нет в Lua-заглушках.

Sends mouse move message with the specified X and Y values.

Поля параметров call-tip (интерпретация структуры, не восстановленные типы):

| № | Имя (`@K[209]`) | Описание (`@K[211]`) |
| --- | --- | --- |
| 1.0 | X | X value |
| 2.0 | Y | Y value |
| 3.0 | Absolute | Use absolute (a.k.a Screen) coordinates? Alternative is relative (a.k.a Client) coordinates.  |

<details><summary>Исходная структура call-tip</summary>

```json
{
  "@K[202]": {
    "1.0": {
      "@K[209]": "X",
      "@K[211]": "X value"
    },
    "2.0": {
      "@K[209]": "Y",
      "@K[211]": "Y value"
    },
    "3.0": {
      "@K[209]": "Absolute",
      "@K[211]": "Use absolute (a.k.a Screen) coordinates? Alternative is relative (a.k.a Client) coordinates. "
    }
  },
  "@K[203]": "Sends mouse move message with the specified X and Y values."
}
```

</details>
