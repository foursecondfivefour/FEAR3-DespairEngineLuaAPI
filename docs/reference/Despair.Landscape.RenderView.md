## Despair.Landscape.RenderView.SetRenderingEnabled

Сигнатура не восстановлена: записи нет в Lua-заглушках.

Enables or disables rendering in the render view.

Поля параметров call-tip (интерпретация структуры, не восстановленные типы):

| № | Имя (`@K[209]`) | Описание (`@K[211]`) |
| --- | --- | --- |
| 1.0 | Enabled | True is rendering should be enabled. False if render should be disabled. |
