## Despair.Poise.VarEdit.Edit

Сигнатура не восстановлена: записи нет в Lua-заглушках.

Change the value of a animation variable directly in the graph

Поля параметров call-tip (интерпретация структуры, не восстановленные типы):

| № | Имя (`@K[209]`) | Описание (`@K[211]`) |
| --- | --- | --- |
| 1.0 | @K[209] | Name of the variable to edit |
| 2.0 | @K[209] | Value of the variable to modify |

<details><summary>Исходная структура call-tip</summary>

```json
{
  "@K[202]": {
    "1.0": {
      "@K[209]": "@K[209]",
      "@K[211]": "Name of the variable to edit"
    },
    "2.0": {
      "@K[209]": "@K[209]",
      "@K[211]": "Value of the variable to modify"
    }
  },
  "@K[203]": "Change the value of a animation variable directly in the graph"
}
```

</details>
