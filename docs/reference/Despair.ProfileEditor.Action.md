## Despair.ProfileEditor.Action.AddBinding

Adds a input binding to the specified controller button.

Поля параметров call-tip (интерпретация структуры, не восстановленные типы):

| № | Имя (`@K[209]`) | Описание (`@K[211]`) |
| --- | --- | --- |
| 1.0 | InputName | Name of the Input to bind. |
| 2.0 | BindingName | Name of bind. |
