# Despair.Bling.RenderView

[Индекс](../API.md)

## Despair.Bling.RenderView.SetAsDropTargetCentered

Сигнатура не восстановлена: записи нет в Lua-заглушках.

Ends a drag and drop operation at a centered location of control.

<details><summary>Исходная структура call-tip</summary>

```json
{
  "@K[202]": {},
  "@K[203]": "Ends a drag and drop operation at a centered location of control."
}
```

</details>

## Despair.Bling.RenderView.SetAsDropTargetXY

Сигнатура не восстановлена: записи нет в Lua-заглушках.

Ends a drag and drop operation at the specified location.

Поля параметров call-tip (интерпретация структуры, не восстановленные типы):

| № | Имя (`@K[209]`) | Описание (`@K[211]`) |
| --- | --- | --- |
| 1.0 | X | Local X coordinate to end dragging. |
| 2.0 | Y | Local Y coordinate to end dragging. |

<details><summary>Исходная структура call-tip</summary>

```json
{
  "@K[202]": {
    "1.0": {
      "@K[209]": "X",
      "@K[211]": "Local X coordinate to end dragging."
    },
    "2.0": {
      "@K[209]": "Y",
      "@K[211]": "Local Y coordinate to end dragging."
    }
  },
  "@K[203]": "Ends a drag and drop operation at the specified location."
}
```

</details>
