# Despair.BusEditor.StandardToolbar

[Индекс](../API.md)

## Despair.BusEditor.StandardToolbar.Execute

Сигнатура не восстановлена: записи нет в Lua-заглушках.

Clicks the toolbar button specified.

Поля параметров call-tip (интерпретация структуры, не восстановленные типы):

| № | Имя (`@K[209]`) | Описание (`@K[211]`) |
| --- | --- | --- |
| 1.0 | Button | Button name to click. The mouse over text for a given button is the value that should be used to click it via LUA. |

<details><summary>Исходная структура call-tip</summary>

```json
{
  "@K[202]": {
    "1.0": {
      "@K[209]": "Button",
      "@K[211]": "Button name to click. The mouse over text for a given button is the value that should be used to click it via LUA."
    }
  },
  "@K[203]": "Clicks the toolbar button specified."
}
```

</details>

Поля параметров call-tip (интерпретация структуры, не восстановленные типы):

      "@K[211]": "The Checked value of the specific Button."

</details>
